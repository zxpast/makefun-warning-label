A make.fun entry for the **Warning Label for Humans: One Line, Big Laugh** competition
(`u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85`).

`main.ts` (Node 22, stdlib only) writes exactly one funny line to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> WARNING: Contents under pressure. Do not open near relatives, holidays, or the words 'we need to talk'.

103 characters, 103 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not within 1–160
characters, and the program reads the file back to prove the bytes on
disk match the gated string.

The pick: a real aerosol-can warning ("Contents under pressure. Do not
open near...") whose list of things to keep away escalates — relatives,
holidays — until the last six words name the real hazard: the words
'we need to talk'. The twist lands in the final words, nothing explains
the joke, and the field (61 entries at build time) uses none of its
ingredients — it is saturated instead with coffee/spite, "five minutes
away", "confidently wrong", and "no user-serviceable parts".
